# 简历描述（项目经历话术）

## 一句话版本

**Agent 自动测试系统**：基于 LangGraph + LangChain 的 API/UI 双覆盖智能测试平台，Agent 依据 OpenAPI 契约自动生成测试计划、执行与重试、归因缺陷并产出可视化报告；可无缝切换规则引擎与真实 LLM 两种大脑。

## STAR 完整版

**S（背景）**：被测系统为 Flask 待办清单服务（契约驱动），面临接口回归成本高、UI 验证靠人工、问题定位慢的痛点；同时希望沉淀一套「测试+AI」结合的自动化能力。

**T（任务）**：从零搭建一套 Agent 自动测试系统，覆盖 API 接口测试与 Web UI 测试，能自动发现缺陷并输出可审计报告。

**A（行动）**
- 用 LangGraph 编排四节点流水线：planner（生成测试计划）→ executor（执行+自动重试）→ critic（失败归因+覆盖率）→ reporter（HTML/JSON 报告）；
- 抽象 Brain 层：规则引擎 MockBrain（离线可跑、结果确定）与 LLMBrain（LangChain with_structured_output 结构化生成 12~20 条用例并归因缺陷），未配 Key 自动降级；
- 工具层保持确定性：requests 执行接口断言，系统 Chrome 无头模式做真实渲染断言与截图（另内置 Selenium 后端可切换）；
- 失败重试与归因分离：5xx/网络错误指数退避重试 3 次，仍失败才进入归因，避免 Flaky 误报；
- 被测系统注入 3 个真实缺陷（契约不符 500、缺失参数校验、不稳定服务 503），演示 Agent 真实发现缺陷；
- 为项目自身编写 30 项 pytest（含 2 项缺陷基准 xfail），全部通过。

**R（结果）**
- 单次运行 18 条用例（15 API + 3 UI），自动发现 2 个缺陷并正确归类（contract / bug），全程约 15 秒；
- 报告含 Agent 思考轨迹、缺陷证据、覆盖率与 UI 截图，可直接交付业务方；
- 无 API Key 也能完整演示（MockBrain），接入真实 LLM 只需配置环境变量。

## 投「软件测试工程师」版本（前 3 行重点）

> 接口自动化测试框架：以 OpenAPI 契约为基准自动生成正/反/边界/契约用例，覆盖 15+ 接口场景；
> 缺陷管理：自动重试区分 Flaky 与真缺陷，失败自动归类（bug/contract/flaky）并生成含证据的缺陷报告；
> UI 自动化：真实浏览器渲染断言 + 自动截图，覆盖关键页面冒烟；项目自身 30 项 pytest 全绿。

## 投「Agent 开发工程师」版本（前 3 行重点）

> LLM 应用落地：LangChain 结构化输出驱动 Agent 自动生成测试计划与缺陷归因，Prompt 工程化；
> Agent 架构：LangGraph 状态机编排 planner/executor/critic/reporter，Brain 抽象实现规则引擎与 LLM 无缝切换；
> 工程化：确定性工具层（Tool 抽象）、可观测 trace、失败降级、pytest 回归保障。
